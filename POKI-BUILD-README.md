# DinoCraft Poki Inspector build
Poki preview: https://chloesoldit-ops.github.io/DINO-CRAFT/poki/
Normal DinoCraft: https://chloesoldit-ops.github.io/DINO-CRAFT/

The normal game at /index.html has NOT been replaced.

Poki package contents: poki/index.html, poki/three.min.js (Three.js r155), poki/THREE-LICENSE.txt. Upload these three files together, keeping the index.html at the top of your uploaded folder.

Test at https://inspector.poki.dev/ by dragging in the extracted poki folder.
Official requirements: https://developers.poki.com/guide/requirements-quality
SDK: https://developers.poki.com/guide/sdk-html5

Implemented: local Three.js; only official Poki SDK loaded remotely; SDK events on loading/play/pause, commercial breaks on pause resume and after arena death; no ad-block messages; controls input muted during ads; incognito-safe initial inventory; original Sporeburst and Void Moth monsters, Magma Depths and Void Realm names; testing-only cheat options hidden.
No online multiplayer, external chat, or external account login.

IMPORTANT: This is a TEST/INSPECTOR build, not an approved Poki release.
