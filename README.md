# DinoCraft 🦖

**Version 3.6 — Anti-Copy Edition**

Official free-to-play game: https://chloesoldit-ops.github.io/DINO-CRAFT/

DinoCraft is a browser-based dinosaur adventure with six worlds, building, mining, bosses and mobile/desktop controls.

## Controls
Choose **Automatic**, **Mobile / Touch**, or **Computer / Keyboard & Mouse** on the title screen or later in Pause → Settings. The preference is saved on the current browser.

- Desktop: WASD movement, mouse look, mouse wheel or 1–9 for the hotbar, E for backpack, ESC for pause.
- Mobile: joystick to move, swipe to look, touch buttons to jump, fight, and place blocks.
- Creative access is available only after entering the testing code.
